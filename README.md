# Baton 카탈로그

Baton 앱에서 쓰는 **워크플로우 · 에이전트 · 팀**을 모아 두는 곳입니다.
좋은 것을 올리고, 필요한 것을 골라 받습니다.

- **받는 쪽**: 앱의 `실행 › 가져오기 › 카탈로그에서` 에서 묶음을 골라 가져옵니다.
  가져온 정의는 내 기기의 `~/.baton/{workflows,agents,teams}` 에 파일로 놓입니다.
- **올리는 쪽**: 브랜치를 따서 PR 을 올립니다. 절차는 [CONTRIBUTING.md](./CONTRIBUTING.md),
  무엇이 들어올 수 있는지는 **[POLICY.md](./POLICY.md)** 가 정본입니다.

## 먼저 읽을 것 — 여기 있는 묶음은 글이 아니라 실행 권한입니다

워크플로우는 내 기기에서 **명령을 돌립니다**(`shell` 은 `/bin/sh -c` 를 그대로 실행).
에이전트 지시문도 마찬가지로 도구를 쥔 세션에 그대로 들어갑니다.
그래서 이 레포는 두 겹으로 막습니다:

1. **올릴 때** — CI 가 문법·의존성·위험을 검사하고, 사람(CODEOWNERS)이 **명령 원문을 읽고** 승인합니다.
2. **받을 때** — 앱이 가져오기 전에 위험 요약과 **명령 원문**을 보여 주고 동의를 받습니다.

두 겹 다 지나도 마지막 판단은 받는 사람 몫입니다. **읽지 않고 가져오지 마세요.**

## 구조

```
index.json              앱이 읽는 목록 하나 (CI 가 생성 — 손으로 고치지 않습니다)
catalog/
  <묶음-id>/
    pack.json           이름 · 설명 · 버전 · 위험 신고 · 비파일 의존 선언
    workflow.yaml       (있으면)
    agents/*.md         이 묶음이 부르는 에이전트
    teams/*.yaml        (있으면)
```

묶음 하나는 **스스로 완결**해야 합니다 — 부르는 에이전트와 자식 워크플로우를 모두 담습니다.
받는 쪽에서 「이 파일이 빠졌습니다」가 뜨면 그건 올린 쪽의 실수입니다.
